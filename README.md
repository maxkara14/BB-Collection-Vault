# BB Collection Vault

Коллекционная витрина для SillyTavern: сохраняет лор-орбы из чата и собирает редкие ачивки за важные моменты ролки.

Расширение задумано как приятный архив для тех штук, которые жалко терять между сообщениями: красивых орбов, сюжетных фрагментов, маленьких побед, провалов и памятных сцен.

## Что умеет

- Сохраняет все `::LORE_ORB_START:: ... ::LORE_ORB_END::` и `::SILVER_ORB_START:: ... ::SILVER_ORB_END::` блоки из ответов персонажа.
- Показывает коллекцию орбов с поиском, фильтром редкости и полным текстом фрагмента.
- Удаляет орбы из коллекции, если сообщение-источник было удалено или орб пропал из него.
- Показывает уведомления об орбах только для выбранных редкостей. По умолчанию это `Rare` и `Anomaly`.
- Сохраняет ачивки из маркеров `[ACHIEVEMENT: эмодзи | название | описание | редкость]`.
- Может просить модель выдавать ачивки только за действительно важные события в сцене.
- Соблюдает кулдаун ачивок на стороне расширения, чтобы достижения не сыпались каждое сообщение.
- Добавляет локальные достижения за саму коллекцию, например за первый орб или первую редкость.
- Позволяет вручную удалить отдельный орб или ачивку.
- Поддерживает всплывающие уведомления, звук, положение уведомлений, масштаб и отдельные цвета.

## Как это работает

### Орбы

Орбы берутся из скрытых блоков, которые генерирует [BB-UI-Regex-Pack](https://github.com/maxkara14/BB-UI-Regex-Pack). Коллекция не заменяет Regex Pack и не отвечает за красивый рендер орбов в самом чате. Она просто находит исходные блоки, сохраняет их в метаданные текущего чата и показывает в отдельном окне.

Сохраняются все орбы. Настройки редкости влияют только на уведомления, а не на саму коллекцию.

### Ачивки

Ачивка попадает в коллекцию, если в ответе модели есть маркер:

```txt
[ACHIEVEMENT: 🏆 | Название | Короткое описание | rare]
```

Если включен промпт ачивок, расширение добавляет модели инструкцию: выдавать достижения редко и только за значимые моменты. Если кулдаун еще не прошел, расширение добавляет отдельную инструкцию не выдавать ачивку в текущем ответе.

Даже если модель нарушит правило и выдаст маркер слишком рано, локальный кулдаун может проигнорировать такую ачивку.

## Настройки

### Коллекция

- **Включить коллекцию** - главный переключатель расширения.
- **Сохранять орбы из чата** - добавляет все найденные орбы в коллекцию.
- **Собирать ачивки** - включает сохранение чат-ачивок и локальных достижений коллекции.
- **Просить модель выдавать ачивки** - подключает промпт для редких достижений.
- **Показывать кнопку коллекции поверх чата** - включает маленькую перетаскиваемую кнопку с количеством орбов.
- **Не сохранять одинаковые ачивки** - помогает избежать дублей.
- **Применять кулдаун в расширении** - фильтрует слишком частые достижения.

### Уведомления

Здесь настраиваются только всплывающие уведомления и звук. Орбы продолжают сохраняться, даже если уведомления выключены.

- уведомления об орбах;
- уведомления об ачивках;
- звук уведомлений;
- отдельный звук для орбов и ачивок;
- угол экрана, размер и громкость;
- редкости орбов, для которых нужно показывать уведомления;
- отдельные цвета уведомлений.

### Вид

Настройки внешнего вида меняют окно коллекции и кнопку поверх чата:

- тема;
- плотность панели;
- акцентный цвет коллекции.

Цвета всплывающих уведомлений находятся во вкладке **Уведомления**.

### Промпт

Во вкладке промпта можно изменить текст, который просит модель выдавать ачивки. Там же есть отдельный промпт запрета на время кулдауна.

### Отладка

Во вкладке отладки есть кнопки для проверки уведомлений, пересбора коллекции из чата, сохранения тестовой ачивки, вывода состояния в консоль и очистки коллекции текущего чата.

## Хранение данных

Данные сохраняются отдельно для каждого чата:

```js
chatMetadata.bb_collection_vault
```

Если удалить сообщение с орбом, расширение при следующем сканировании уберет этот орб из коллекции. Если удалить орб или ачивку вручную, расширение запомнит это и не вернет удаленный элемент при обычном перескане.

## Консольные команды

```js
BBCollectionVault.open()
BBCollectionVault.scan()
BBCollectionVault.rebuild()
BBCollectionVault.store()
BBCollectionVault.cooldown()
BBCollectionVault.promptState()
```

## Установка

1. Откройте SillyTavern.
2. Перейдите в `Расширения -> Установить расширение`.
3. Установите расширение из репозитория или поместите папку `BB-Collection-Vault` в `public/scripts/extensions/third-party`.
4. Перезагрузите страницу.
5. Откройте `BB Collection Vault` в списке расширений.
